Browser Ad Killer 隐私政策

适用于 Microsoft Edge 扩展「Browser Ad Killer」· 版本 0.2.0 · 最后更新：2026-11-22

一句话总结

这个扩展不收集、不上传、不共享你的任何个人数据。所有处理都在你的设备上完成。

扩展会接触哪些数据

  • 网页地址（URL）：用于匹配域名级的拦截规则与元素隐藏规则。URL 只在本地内存与扩展存储中短暂存在，不会发送到任何服务器。
  • 页面元素：内容脚本只删除广告位/推广卡片对应的 DOM 节点，不读取表单内容、密码、输入历史或页面文本。
  • 拦截计数：本地累计的拦截数量与命中规则，仅存于扩展本地存储，用于弹窗与状态展示。
  • 设置：开关、自定义规则、订阅列表，存于扩展本地存储（chrome.storage.local）。

会发起哪些网络请求

  • 通过 HTTPS 拉取公开的广告拦截订阅（AdGuard Base / AdGuard Chinese / EasyList China / anti-AD 等），用于更新规则。请求只包含固定的订阅 URL 与通用 User-Agent，不携带设备标识或用户标识。
  • 通过 HTTPS 检查扩展自身的新版本（GitHub / jsDelivr 镜像）。请求同样不含个人信息。
  • 除此之外，扩展不会连接任何统计、分析、广告或崩溃上报服务。

不会做的事

  • 不要求登录，不申请账号。
  • 不读取或上传浏览历史、书签、Cookie、密码。
  • 不注入远程代码；扩展的全部脚本随安装包分发。
  • 不向第三方出售、出租或共享任何数据。

权限用途

  • declarativeNetRequest：按规则拦截广告与追踪请求。
  • <all_urls>：广告域名出现在任意站点，拦截需全站生效。
  • scripting：向已打开页面注入元素隐藏样式。
  • storage / unlimitedStorage：保存规则表与设置（规则表可达数十万域名）。
  • tabs / activeTab / alarms：判断当前页面类型、做一次性诊断、定时刷新订阅。

数据删除

卸载扩展即删除其全部本地数据。你也可在扩展选项页点击「恢复默认」清空自定义规则与统计。

联系方式

问题或数据相关请求：GitHub Issues。

Privacy Policy (English)

For the Microsoft Edge extension “Browser Ad Killer” · version 0.2.0 · last updated 2026-11-22

Summary

The extension collects nothing, transmits nothing about you, and shares nothing. All processing happens on your device.

What it touches

  • Page URLs — matched locally against domain-level block and cosmetic rules. Never sent to any server.
  • Page elements — content scripts remove ad DOM nodes only. They never read form fields, passwords, or page text.
  • Block counters — stored locally for the popup display.
  • Settings — stored in chrome.storage.local.

Network requests it makes

  • HTTPS fetches of public blocklists (AdGuard Base / Chinese, EasyList China, anti-AD) to refresh rules. Requests contain only the subscription URL and a generic User-Agent.
  • HTTPS update checks against GitHub / jsDelivr mirrors, containing no personal data.
  • No analytics, no telemetry, no crash reporting, no ad services.

What it never does

  • No sign-in, no account.
  • No reading or uploading of history, bookmarks, cookies or passwords.
  • No remote code; all scripts ship inside the package.
  • No sale, rental or sharing of data with third parties.

Data removal

Uninstalling the extension deletes all of its local data. The options page also offers “reset to defaults”.

GitHub Issues.
